# 家庭助手首轮试用记录

用途：连续观察两周真实生活中的使用，区分即时问答价值与资料积累价值。技术功能验收已记录在 011 产品计划的实施记录中。

开始日期：首次自然使用当天填写。低频需求尚未出现时延长观察。

## 记录方法

只记录判断产品是否有用所需的信息。问题可以用“找设备说明书”“查询钥匙位置”等类别描述，不必抄录私人正文。调试、演示和专门测试分别标记，不计入自然使用。

## 两周后判断

- 是否出现至少三次由独立真实生活需求触发的使用？
- 是否至少两次复用了以前保存的内容，省去翻找、重传或重复解释？
- 保存、找回和更正的成本是否小于得到的帮助？
- 若主要使用一次性问答，哪个即时理解环节最值得改善？
- 若找回失败，是未保存、叫法不同、对象不明确、正文未识别，还是信息已过时？

## 家人试用

在出现共同需要的材料或信息后，再邀请家人用独立账号尝试。记录其是否能独立完成保存和找回、是否理解共享范围，以及是否在另一个真实需求中主动回来使用。一次指导演示不作为自然复用证据。
