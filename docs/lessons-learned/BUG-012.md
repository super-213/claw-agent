# BUG-012：对话历史侧栏重复显示页面标题

- 发现日期：2026-10-30
- 状态：代码已修复，类型检查、导航回归和生产构建通过；未部署。

## 现象与影响

全局导航已经标明“对话”，历史侧栏顶部又显示“对话”，信息重复并占据历史列表上方空间。

## 复现条件

进入 `/chat` 并展开历史侧栏；宽屏使用左侧全局导航，窄屏使用底部导航。

## 排查证据

- 用户截图显示左侧导航和历史侧栏同时标注“对话”。
- `SessionSidebar.tsx` 在新建按钮前单独渲染 `h2`；对应样式设置标题行最小高度为 72px。
- 该标题行还容纳窄屏关闭按钮，直接删除整行会同时删除抽屉关闭入口。

## 原因

已确认：历史侧栏沿用独立页面标题，在已有全局导航的布局中形成重复。这是前端信息组织问题，不涉及模型请求或工具调用。

## 修复内容

- 删除重复标题和标题行样式，调整新建按钮上方间距。
- 将关闭按钮移入新建按钮所在行，窄屏使用两列布局与静态定位，保留可访问名称及关闭行为。
- 侧栏仍通过 `aria-label="历史对话"` 标识。

- `npm --prefix web-react run test -- ../test/web-react/chat/navigation.test.ts`：4 项通过，包含桌面折叠和移动端抽屉打开。
- `npm --prefix web-react run build`：通过；仍有主 JS 超过 500kB 的构建提示。
- `git diff --check`：通过。
- 未执行浏览器视觉验证、真实模型或网络验证；运行服务未重启，未部署。生产资源已本地构建。

已有全局导航的侧栏优先展示操作和列表；移除标题行时检查其中是否还包含移动端关闭等必要控件。
