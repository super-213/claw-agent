# BUG-022：投票选项被家庭页面全局表单样式改成纵列

- 发现日期：2026-10-30
- 状态：开发中发现，代码已修复并验证；运行服务未更新、未部署。

## 现象与影响

家庭投票手机截图中，单选控件、选项和统计各自纵向堆叠，单个选项占用过多高度，偏离紧凑投票行设计。发生于本轮新卡片开发。

## 复现条件

把活动卡片放入家庭页面详情，在 390px 手机宽度查看投票结果。

## 排查证据

首次浏览器截图直接显示控件位于选项上方；活动类选择器的 grid 布局被家庭页面更高优先级的 label 样式覆盖，输入控件同时继承了普通输入框尺寸。

## 原因

已确认：独立卡片的低优先级样式没有限定与宿主表单样式的组合，组件单测通过不足以证明嵌入真实页面后的视觉布局正确。

## 修复内容

针对家庭页面中的活动卡片定义更明确的投票行、复选标签和原生选择控件尺寸，保持全局表单规则不变。

## 验证结果

修复后重新执行 `scripts/validate_family_activities.py`，三成员流程、1440/390px、明暗主题及到期销毁通过；人工查看新手机截图，选项和票数已恢复同一行。截图在 `.data/validation/family-activities/`。未做 iPhone 真机验收，未部署。

## 后续预防及相关代码

新卡片必须在真实宿主页面渲染后检查，包含表单禁用状态、手机及明暗主题。相关代码：`web-react/src/features/family-activities/activities.css`、`ActivityCard.tsx`、`scripts/validate_family_activities.py`。
