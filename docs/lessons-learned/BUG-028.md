# BUG-028：全局主题变量被统计页覆盖，前端视觉规范混用

- 发现日期：2026-11-05
- 状态：代码已修复；构建、前端单测及独立浏览器视觉矩阵通过；完整旧浏览器流程有未通过项，未部署。

## 现象与影响
首页已有粗描边，但大圆角、低饱和色、模糊投影与玻璃背景混用；公共弹窗和统计页不能稳定继承统一主题。

## 复现条件
加载前端全局样式；查看首页、聊天、统计页和弹窗。明暗主题、移动与桌面均涉及。

## 排查证据
- `app.css` 在 `base.css` 后引入 `dashboard.css`；后者顶层 `:root` 重复定义 `--surface`、`--radius`、`--shadow` 等变量，值分别包含半透明表面、8px 圆角和模糊投影。
- `workspace-tokens.css` 原有 12px 圆角，首页及聊天组件还存在硬编码 8–24px 圆角；日历抽屉和菜单另有模糊投影。
- 首轮新截图发现工作台标签的高优先级组件规则仍保留圆角，随后补齐相同作用域规则。

## 原因
已确认：全局主题变量重复定义和组件局部硬编码共同造成视觉规则混用。审美观感并非单个技术原因能证明，本记录仅陈述可观察的样式冲突。

## 修复内容
- 统计页复用基础主题，只保留图表专用 teal 色。
- 浅色统一奶白底和黄、蓝、粉强调色；深色保留独立可读配色。正文次要色进一步调整，满足强调色底上的对比要求。
- 共享样式集中管理直角、结构描边、3/5/8px 硬投影、标题层次、主操作按压反馈与显性焦点；信息密集列表维持轻量分隔。
- 清除共享组件旧渐变、背景模糊和呼吸动画，校正移动端及日历抽屉。
- 更新既有浏览器测试中聊天输入框的旧颜色断言，并验证新描边和直角。
