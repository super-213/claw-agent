# BUG-021：普通技能按钮函数名称触发 Hooks 校验

- 发现日期：2026-10-30
- 状态：开发中发现，代码已修复并验证；运行服务未更新、未部署。

## 现象与影响

执行本轮全量 ESLint 时，既有 `SkillsView.tsx` 的按钮回调调用 `useSkill` 被报告为在 callback 内调用 Hook，阻断 lint。

## 复现条件

运行 `npm run web:lint`；`useSkill` 实际是处理打开会话的普通异步事件函数。

## 排查证据

ESLint 定位 `SkillsView.tsx:59`，规则为 `react-hooks/rules-of-hooks`。查看函数体确认它只读状态、创建会话并导航，没有声明或调用 React Hook。

## 原因

已确认：普通事件处理器使用 `use` 加大写字母的命名形态，被静态规则视为 Hook。不是实际 Hook 调用顺序错误。

## 修复内容

将该函数及按钮调用改名为 `openSkill`，不改变行为。

## 验证结果

修改后全量 ESLint 通过；技能入口包含在前端全套回归中通过。未部署。

## 后续预防及相关代码

只给自定义 Hook 使用 useX 命名；事件处理使用 open／handle 等动词。相关代码：`web-react/src/features/plugins/SkillsView.tsx`、`test/web-react/home/skills-view.test.ts`。
