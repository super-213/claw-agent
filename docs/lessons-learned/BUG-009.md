# BUG-009：更多二级页缺少回程，杂项菜单职责重复

- 发现日期：2026-10-30
- 状态：代码已修复，相关回归和浏览器验证通过；未重启运行服务或部署。

## 现象与影响

“更多”中的最近对话、家庭动态、账号与设置和成员管理缺少明确返回入口。目录平铺重复入口，页面标题重复，用户难以理解菜单职责。非法 section 参数会留下没有实际内容的页面。

## 复现条件

登录后进入 `/home/more`，打开任一 `section` 二级页；直接打开 `/home/more?section=unknown`。管理员进入成员管理时原页面提前返回 TaskAdmin，不经过统一页面结构。

## 排查证据

- 原 MoreView 只渲染二级内容，无返回链接；admin 分支在通用结构之前直接返回。
- HomePage 页头和 MoreView 同时渲染“更多”标题。
- HomeNav 已有四个主入口；ChatWorkspace 的 SessionSidebar 已提供历史对话列表，“更多”再次列出最近对话。
- activity 调用 homeApi.activity，渲染 inventory 操作，不能等同完整家庭动态。
- 原滚动记录只按 pathname 保存，所有 section 共用位置。
- 独立离线、安装和看板页面原有工作台或对话链接，但缺少返回更多的路径。用户所说的“没有退出按钮”对这些页面体现为回程不一致，并非完全无离开方式。

## 原因

已确认：更多页面以 section 条件分支堆叠功能，未统一处理二级标题、父级回程、有效参数与滚动位置；菜单职责和已有主入口重复。这里是前端导航与信息组织问题，未涉及模型或业务工具调用。

## 修复内容

- 保留四个主入口，更多按个人设置、便捷使用、管理员工具分组，补充用途说明。
- 移除最近对话菜单，快捷导航指向 `/chat`；旧 sessions 二级链接继续兼容并提供回程。
- 家庭动态改名“物品操作记录”；成员管理改为“家庭成员管理”，保留迁移核对功能。
- 外观归入账号与设置，移除账号页重复的离线入口。
- 页头统一标题及“返回更多”链接，直接访问也可返回；成员页纳入通用导航。
- 更多目录与各 section 分别记录滚动位置；切换时将朗读焦点放在标题。
- 未知参数、普通用户的 admin 参数回到更多目录，不展示管理员内容。
- 安装、离线、看板提供明确返回更多的入口。

## 2026-10-30 后续产品调整：取消独立离线页

用户明确要求删除“离线随身页”，改为数据自动缓存。已移除菜单和页面组件，旧 `/offline` 路由转到工作台；常用业务页面通过 `features/offline/responseCache.ts` 自动保存实际读取的数据，网络失败时在原页回退（含已读取的对话正文）。不缓存凭据、管理员配置或二进制附件，不自动提交旧离线草稿。取消 App 的旧快照刷新，恢复网络时改为刷新页面查询。详情见 `docs/claw-agent-web-upgrade.md`。

自动缓存验证期间发现跨标签退出未离开原页面的问题，另记录于 [BUG-010](BUG-010.md)。本节取代上文“保留离线页并添加返回入口”的当前产品行为，上文作为首次修复证据保留。
