# BUG-020：不要发布草稿被误判为禁止创建

- 发现日期：2026-10-30
- 状态：开发中发现，代码已修复并验证；运行服务未更新、未部署。

## 现象与影响

真实模型验收中，用户要求“先拟一个家庭投票草稿……现在不要发布”，创建工具连续失败，没有返回应有的私有草稿卡片。仅发生于本轮开发验收。

## 复现条件

原生 `family_poll_create` 请求包含明确草稿意图，同时原话包含“不要发布”。

## 排查证据

首次五场景真实模型验收为 4/5：草稿场景反复调用 `family_poll_create` 失败，另外创建投票、创建接龙、修改和删除通过。代码中否定检查 `不要(?:创建|发布)` 在草稿判定之前运行。

## 原因

已确认：把“禁止发布”错误等同于“禁止创建”，没有区分私有草稿和已发布活动两个动作。不是模型不具备工具调用能力。

## 修复内容

只对明确“不要创建／不用创建”拒绝创建；“不要发布／草稿／先拟”进入 draft 路径，缺少用户明确要求的截止时刻时保留待补充字段。

## 验证结果

新增 `test_native_draft_request_not_to_publish_and_missing_time` 通过。修复后只追加一次真实模型草稿复测，通过 `tool_load → family_poll_create` 返回未发布卡片；真实验收累计五类场景全部通过，总共六个隔离请求。报告仅保留合成场景名与工具名。未部署。

## 后续预防及相关代码

针对“先拟／不要发布／不要创建”分别验证意图，不只测试完整直接发布。相关代码：`agent_runtime/family_activity_tools.py`、`scripts/evaluate_family_activities_chat.py`、`test/test_family_activities.py`。
